# Bluetooth Hunter

**A feature-rich Linux desktop application for discovering, monitoring, and managing nearby Bluetooth devices, with controls to disconnect your own connected devices.**

**Language:** Go (Golang)  
**GUI Framework:** Fyne  
**Bluetooth Backend:** BlueZ (Linux Bluetooth Stack)  
**Communication:** D-Bus  
**Platform:** Linux (Ubuntu and other BlueZ-based distributions)

**Project Goal:** To develop a lightweight, user-friendly desktop application that scans nearby Bluetooth devices, displays their information and connection status, monitors signal strength, and allows users to manage their own Bluetooth connections.
